# Warehouse DWH Demo for Data Engineering Roles

This repository contains a production-style retail warehouse analytics demo built to support a senior data engineering and BI role application. The solution is designed around a modern warehouse data platform pattern: source ingestion, star-schema analytics, curated fact tables, KPI reporting, and Power BI consumption.

The project intentionally uses a simple, portable stack that runs locally without cloud subscription costs:

- Python for ingestion and transformation
- SQLite as the warehouse-ready database
- SQL for dimensional modeling and aggregations
- Power BI as the reporting layer
- A clear Azure-compatible architecture narrative for candidate presentation

## Business context

The demo models an omnichannel e-commerce warehouse operation. It tracks:

- Customers and market segmentation
- Product catalog and categories
- Warehouse inventory and fulfillment centers
- Orders, shipments, and sales performance
- KPI reporting by region, warehouse, time, and product

This is a good fit for a data warehouse/BI role because it mirrors the operational decisions a warehouse or retail analytics team must make:

- Which product families drive sales?
- Which warehouse locations are performing best?
- Which regions have the highest gross margin?
- Are fulfillment and shipment KPIs healthy?

## Architecture

The demo follows a modern warehouse design with a medallion-style flow:

1. Raw ingestion layer
   - Customer, product, warehouse, and order files are generated locally.
2. Staging layer
   - Raw CSV data is normalized into a conformed warehouse schema.
3. Curated warehouse layer
   - Dimension tables and a fact table are created in SQLite.
4. Reporting layer
   - Power BI imports CSV summaries for dashboarding.

The logical model is a star schema:

- dim_customer
- dim_product
- dim_warehouse
- dim_date
- fact_order

## Local setup

### Prerequisites

- Python 3.10 or newer
- Optional: Power BI Desktop

### Install Python dependencies

```bash
cd warehouse-dwh-demo
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
# or .venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

If you want the simplest setup, this repo uses the Python standard library and does not require heavy packages. The `requirements.txt` file can remain minimal or be omitted. The included script works with the base Python runtime.

### Generate raw source data

```bash
python scripts/generate_demo_data.py
```

This creates CSV files under `data/raw` for customers, products, warehouses, and orders.

### Build the warehouse database

```bash
python scripts/build_warehouse.py
```

This creates a SQLite warehouse database at `data/warehouse/warehouse_demo.db` and writes a curated summary CSV to `data/published/warehouse_sales_summary.csv`.

### Validate database contents

```bash
python -c "import sqlite3; conn = sqlite3.connect('data/warehouse/warehouse_demo.db'); print(conn.execute('SELECT COUNT(*) FROM fact_order').fetchone()); print(conn.execute('SELECT COUNT(*) FROM dim_customer').fetchone()); conn.close()"
```

3. Product and customer analysis

4. Operational view

### Example DAX measures

```DAX
Total Revenue = SUM('warehouse_sales_summary'[gross_revenue])
Total Orders = SUM('warehouse_sales_summary'[total_orders])
Gross Margin % = DIVIDE(SUM('warehouse_sales_summary'[gross_margin]), SUM('warehouse_sales_summary'[gross_revenue]))
Avg Order Value = DIVIDE([Total Revenue], [Total Orders])
```

See `dashboard/powerbi_dashboard_spec.md` for a full layout and KPI specification.

## Azure-compatible deployment story

Although the local demo runs in SQLite for simplicity, the architecture is intentionally Azure-ready and maps cleanly to a production data platform:

- Source data landing: Azure Data Lake Storage (ADLS)
- Orchestration: Azure Data Factory or Databricks Workflows
- Processing: Azure Databricks / Apache Spark
- Warehouse: Azure SQL or Synapse SQL
- Security: Key Vault and Managed Identity
- Reporting: Power BI

This makes the project a strong story for a cloud-focused data engineering role without forcing the demo to require a paid Azure setup.

## Azure DevOps CI/CD pipeline

This demo includes a pipeline definition at the repository root: `azure-pipelines.yml`.

What it does:

- triggers on `master` and `feature/*`
- validates pull requests to `master`
- installs Python 3.12
- creates source CSV files
- builds the SQLite warehouse and fact/dimension tables
- verifies record counts and revenue totals
- publishes the generated CSV artifacts for Power BI and downstream reporting

Example local equivalent:

```bash
cd warehouse-dwh-demo
python scripts/generate_demo_data.py
python scripts/build_warehouse.py
```
